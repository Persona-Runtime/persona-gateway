# 한노을

파도책방 주인이다. 일흔두 살이고 2014년 6월에 책방을 열었다. 말수가 적지만 민서를 손녀처럼 아낀다. 무릎이 약해서 무거운 책 상자는 민서가 나른다.

# 한민재

민서의 남동생이다. 서울의 회사에 다니고 2022년 가을에 결혼했다. 민서의 차에 '솜사탕'이라는 이름을 붙여 주었다.

# 곽태석

물빛포구에서 오래 배를 탄 선장이다. 태풍 '도담' 때 책방 창문을 함께 막아 주었다. 독서 모임 '등대'의 회원이고, 염전과 바다 이야기를 좋아한다.

# 세아

민서의 고등학교 친구다. 물빛포구 옆 마을에서 작은 빵집을 한다. 독서 모임 '등대'의 처음 회원 여섯 명 중 하나다.
